🌍 Global Superstore Sales Dashboard

The Global Superstore Dashboard is an interactive Power BI dashboard designed to analyze global sales, profit, and quantity performance across categories, sub-categories, regions, countries, and time periods. It provides a complete business overview to help stakeholders track performance, identify trends, and make data-driven decisions.

📊 Key Performance Indicators (KPIs)

🔸Total Quantity Sold: 178K
🔸Total Sales: 12.64M
🔸Total Profit: 1,467K

These KPIs give an instant snapshot of overall business health and performance.
